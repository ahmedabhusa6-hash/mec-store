Research / New Evidence
FACT
GitHub's official API supports creation of an authenticated user's repository through POST /user/repos; fine-grained tokens require repository-creation write permission or administration write permission. This proves GitHub capability, not that the connected GitHub tool exposes an authorized creation action.
Cloudflare Workflows is available on Free and Paid and provides durable multi-step execution, retries, persisted state, and observability.
Current Cloudflare documentation states that Workers Free has a 1,024-step Workflow limit, while Paid can be configured up to 25,000 steps; Free state/log retention is limited to 3 days.
Cloudflare Workflows billing now applies to CPU time, requests, storage, and steps; it must not be described as unlimited $0/month infrastructure.
Oracle OCI Always Free currently provides up to 2 OCPUs / 12 GB memory equivalent for Ampere A1 compute within its Always Free allowance, but provisioning depends on tenancy/home-region capacity and eligibility.
INTERPRETATION
Cloudflare Workflows is a strong orchestration candidate, but not sufficient by itself as the sole long-lived system-of-record for the Central Runtime under the current Free retention limits. External durable state remains required for durable queue/history requirements.
