========================================
لماذا نستخدم المصفوفات؟
الكفاءة: تسمح المصفوفات "بالوصول العشوائي" للعناصر. وهذا يعني أن الوصول إلى أي عنصر يستغرق نفس المقدار من الوقت بغض النظر عن موقعه في المصفوفة.
الملاءمة: التعامل مع مجموعة من المتغيرات من نفس النوع باستخدام مُعرّف واحد.
إنشاء المصفوفات في Python
لا تحتوي Python على دعم مدمج للمصفوفات، لكنها توفر كائن القائمة (list) الذي يمكن استخدامه بشكل مشابه. ومع ذلك، بالنسبة للمصفوفات الرقمية، توفر Python وحدة متخصّصة تُسمى (array) يمكن استخدامها لإنشاء مصفوفات بعناصر من نوع محدَّد.
قائمة Python كمصفوفة
# Creating a list
my_list = [10, 20, 30, 40, 50]
print(my_list)
استخدام وحدة المصفوفات
from array import array

# Creating an array of integer type
my_array = array('i', [10, 20, 30, 40, 50])
print(my_array)
الوصول إلى عناصر المصفوفة
يمكن الوصول إلى عناصر المصفوفة باستخدام الفهرس الخاص بها. تبدأ الفهارس في المصفوفات من 0، مما يعني أنه يتم الوصول إلى العنصر الأول من المصفوفة عن طريق 0، والعنصر الثاني عن طريق 1، وهكذا.
# Accessing the first element
print(my_list[0])  # Output: 10
print(my_array[0])  # Output: 10
تعديل عناصر المصفوفة
يمكن تعديل عناصر المصفوفة عن طريق الوصول إليها باستخدام فهرسها ثم تعيين قيمة جديدة لها.
# Modifying the first element
my_list[0] = 100
my_array[0] = 100

print(my_list)  # Output: [100, 20, 30, 40, 50]
print(my_array)  # Output: array('i', [100, 20, 30, 40, 50])
العمليات الأساسية
الطول: len(my_list) أو len(my_array)
إضافة عناصر: بالنسبة للقوائم، my_list.append(60)؛ وبالنسبة للمصفوفات، my_array.append(60)
إزالة عناصر: بالنسبة للقوائم، my_list.remove(30)؛ وبالنسبة للمصفوفات، my_array.remove(30)
