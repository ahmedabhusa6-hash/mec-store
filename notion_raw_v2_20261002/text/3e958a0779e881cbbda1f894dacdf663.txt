Research / Fresh Evidence
FACT
Render official documentation states Free Key Value instances do not provide data persistence; data is lost when the instance restarts. Paid Key Value supports disk-backed persistence.
Render states Free resources should not be used for production applications; Free Postgres may restart and has no backups.
GitHub official REST documentation confirms an authenticated user can create a repository through POST /user/repos; fine-grained tokens require Administration write or Repository creation write permission.
Cloudflare Workflows is available on Workers Free and Paid. Current documentation lists Free limits including 3,000 Workflow steps/day, 100,000 executions/day, 100 concurrent running instances, 100,000 queued instances, 100 MB persisted state per instance, and 3-day completed-state retention.
Cloudflare Workflows billing currently covers CPU time, requests, storage, and steps; Free still has explicit quotas.
Oracle OCI Always Free permits up to 2 OCPUs and 12 GB memory total for Ampere A1 after trial within Always Free tenancy constraints, but account/tenancy eligibility and regional capacity remain unverified.

A separate durable state/history layer remains necessary.
