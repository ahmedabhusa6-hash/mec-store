Deep Research / Evidence
FACT
GitHub officially supports creating an independent repository for the authenticated user through POST /user/repos. Fine-grained access requires Repository creation write or Administration write permission. This proves platform capability, not availability through the current connector.
Cloudflare Workflows is available on Free and Paid plans and provides durable multi-step execution, automatic retries, persisted state, and observability.
Current Cloudflare Workflows limits include 100,000 executions/day, 100 concurrent running instances, 100,000 queued instances, 100 MB persisted state per Free Workflow instance, and 3-day retention for completed state on Free.
Cloudflare Workflows billing applies to CPU time, requests, storage, and steps; the Free plan is not unlimited $0 production capacity.
Render Free Key Value has no disk persistence; its state is lost on restart. Paid Key Value supports disk-backed persistence.
Current live Render state: central-automation-queue-dev is Free, noeviction, persistenceMode=off; central-automation-state-dev is Free Postgres and expires 2026-10-25.
Render currently contains no independently deployed Central Runtime service.
EVIDENCE
The live connector state and official provider documentation agree that the current Render queue is development-only and cannot satisfy durable production queue requirements.
INTERPRETATION
The immediate blocker is not queue implementation. It is independent codebase/deployment authorization. Building more logic inside an existing business repository would violate the architecture boundary.
Independent Alternatives
Independent GitHub Repository + Cloudflare Workflows: strongest current orchestration candidate after repository isolation; still needs explicit durable operational state strategy and production cost/retention validation.
Independent Repository + self-owned Control Plane + PostgreSQL + Worker: strongest fit for explicit Persistent State, Durable Queue, Lease/Ownership, Reconciliation, and recovery semantics; requires production compute/storage authorization.
Independent Repository + Render Background Worker + paid durable state: conventional and operationally clear; requires paid provisioning.
Render Workflows + external durable state: managed orchestration/retry candidate, but does not remove repository isolation or long-lived system-state requirements.
