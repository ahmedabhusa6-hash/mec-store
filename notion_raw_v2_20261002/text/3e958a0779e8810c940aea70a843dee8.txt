Deep Research / Fresh Evidence
FACT
GitHub's current REST API supports creating a repository for the authenticated user through POST /user/repos. Fine-grained tokens require Repository creation write or Administration write permission. This proves the GitHub-side API capability, not that the currently connected GitHub tool exposes an authorized creation action.
Source: https://docs.github.com/en/rest/repos/repos
FACT
Cloudflare Workflows is available on Free and Paid plans and provides durable multi-step execution, automatic retries, persisted state, and built-in observability.
Current Free limits include:
100,000 Workflow executions/day
100 concurrent running instances
100,000 queued instances
100 MB persisted state per Workflow instance
1,024 steps per Workflow
3-day retention for completed instance state
Source: https://developers.cloudflare.com/workflows/reference/limits/
FACT
Cloudflare Workflows pricing now includes CPU time, requests, storage, and steps. Free has explicit quotas; therefore Free Tier ≠ unlimited $0/month production capacity.
Source: https://developers.cloudflare.com/workflows/reference/pricing/
