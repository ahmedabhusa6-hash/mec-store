========================================
الحالة: معتمد
هذا المرجع يثبت المستوى البصري والإبداعي الحالي المعتمد لـ SKey ERP، ويُستخدم كمرجع عند بناء الكاروسيلات والإعلانات والمواد التسويقية البصرية اللاحقة.
1. الهوية التجارية
YemenSoft = الشركة.
Ultimate Solutions = الشريك/الجهة المرتبطة بالمنتج وفق ما يثبت في المصادر أو ما يقدمه العميل كبيان معتمد.
SKey ERP = المنتج والبطل التجاري والبصري.
القاعدة: لا تُستنتج من العلاقة أي ملكية أو حصرية أو جهة تطوير أو حقوق قانونية غير موثقة.
2. التموضع
SKey ERP ليس "برنامج فواتير" أو "برنامج محاسبة" بسيطًا.
يُقدَّم كـ منتج أعمال احترافي ومنظومة ERP متكاملة ذات خلفية مؤسسية وتقنية.
الرسالة الجوهرية:
خبرة مؤسسية + خبرة حلول ERP + منتج أعمال حديث.
اجعل SKey هو البطل في الرسالة النهائية، وتظهر YemenSoft وUltimate عندما تخدم القصة والثقة.
3. الحقيقة والمصادر
أولوية الحقيقة:
ملف تحليل SKey المرفق = المرجع الوظيفي الأساسي لقدرات النظام وتكامل عملياته.
الموقع الرسمي لـYemenSoft = هوية الشركة ووصف SKey الحالي.
المصادر الرسمية لـUltimate Solutions = هوية الشركة ومجال حلول ERP.
المصادر الرسمية المرتبطة بالشركتين = دعم العلاقة والسياق.
المصادر الثانوية = للتحقق والاستكشاف فقط.
لا تُدخل أي رقم أو نسبة أو نتيجة أو وعد أداء أو شهادة أو عدد عملاء أو ادعاء تفوق دون مصدر مناسب.
لا تحوّل وجود ميزة إلى ضمان نتيجة مالية.

Premium B2B
Corporate
Confident
Sophisticated
Modern
Technological
العربية: فصحى حديثة، مباشرة، راقية، واثقة وهادئة.
ممنوع النبرة الصاخبة أو الوعود الرخيصة أو المبالغات غير المثبتة.
5. المستوى البصري المعتمد
Luxury Corporate + Cinematic Technology + Visual Storytelling
المرجع البصري المستخلص من تصميمَي 1 و2 في عرض السعودية هو مستوى الجودة ومنطق التكوين وليس هوية تُنسخ.
المطلوب:
عمق سينمائي.
Hero Visual قوي.
طبقات بصرية حقيقية.
إضاءة محسوبة.
صور واقعية عالية الجودة.
هندسة رقمية عند الحاجة.
زجاج/معدن/ضوء/شبكات رقمية عند خدمة الفكرة.
واجهات SKey مدمجة داخل المشهد بدل وضعها كصورة مسطحة.
مساحات سلبية راقية.
Contrast قوي ومدروس.
Composition احترافي غير نمطي.

لا تُغيّر ألوان الشعارات ولا تُنتج هوية جديدة للمنتج.
7. الشعارات المعتمدة
الشعار المرفق لـ YemenSoft = الأصل الرسمي للشركة.
الشعار المرفق لـ SKey ERP = الأصل الرسمي للنظام.
استخدم الملفات الأصلية نفسها.
لا تعِد رسم الشعار.
لا تغيّر النسب.
لا تغيّر الألوان.
لا تضف شعارًا بديلًا.
لا تستخدم شعارات شركات أخرى إلا إذا كانت مرتبطة فعليًا بطلب محدد.
عند ظهور YemenSoft وUltimate وSKey معًا، يكون التسلسل البصري:
Company / Expertise → Convergence → Product
8. معيار الكاروسيل
الكاروسيل يُعامل كقطعة Creative واحدة، وليس مجموعة منشورات.
كل صورة يجب أن تؤدي وظيفة مختلفة.
ممنوع افتراضيًا:
عنوان + نقاط + صورة موظف + زر.
ممنوع استخدام قالب Canva جاهز كمفهوم إبداعي.
ابدأ من:
Concept → Narrative → Visual System → Copy → Composition
وليس:
Copy → Cards → Button

10. قاعدة الاستمرارية
عند تصميم عدة صور مترابطة، يُفضَّل أن ينتقل عنصر بصري أو مفهوم بصري عبر الصور.
مثال:
رمز/عنصر → تحول → منظومة → SKey
أو:
مفارقة → كشف → منتج → نتيجة
ليس مطلوبًا استخدام هذه الأمثلة حرفيًا؛ الفكرة هي وجود تطور بصري حقيقي.
11. معيار النص
الأولوية:
Meaning → Memorability → Clarity → Conversion
لا تملأ التصميم بالنص.
العنوان قد يكون كلمة أو جملة قصيرة جدًا.
كل صورة:
Primary Message → Supporting Line → Optional Micro-copy
لا تستخدم قائمة مزايا إلا إذا كانت هي الفكرة نفسها.
12. التحكم بالتكرار
لا تعاد فكرة سبق تنفيذها بنفس المعنى.
الفكرة السابقة:
"الفاتورة ليست نهاية العملية"
وما يرتبط مباشرة بدورة الفاتورة/المبيعات/المخزون لا يُعاد بنفس الزاوية.
عند التكرار، يجب تغيير:
Core Idea + Persuasion Angle + Visual Metaphor + Narrative Mechanism
تغيير الكلمات وحده لا يُعد تغييرًا كافيًا.
