6. النقد الصارم للنص الذي قدمه المستخدم
النص قوي في الهدف، لكنه غير محكم تشغيلياً في نقاط محددة:
أ. طلب «منهجية التفكير المتسلسل»
المشكلة: صياغتها توحي بطلب كشف سلسلة التفكير الداخلية.
البديل الصحيح: استدلال داخلي غير معروض + عرض النتائج، الأدلة، الافتراضات، والفجوات القابلة للتدقيق.
ب. «اعطني كل شي مهم»
المشكلة: معيار الأهمية غير معرف.
البديل: استخراج إلزامي وفق مخطط ثابت: Facts → Decisions → Rules → Evidence → Assumptions → Gaps → Risks → Dependencies → Changes → Persisted State → Unpersisted State → Next Actions.
ج. «احفظها في التعليمات والذاكرة»
المشكلة: يخلط بين قنوات تخزين مختلفة ولا يحدد السلطة بينهما.
البديل: Notion = canonical persistent project record؛ Persistent Model Context = reusable assistant memory only when explicitly authorized and technically available؛ Conversation = temporary evidence source.
د. «الأشياء التي ما حفظها في Notion احفظها»
المشكلة: غير محدد هل المطلوب حفظها كحقائق، تعليمات، أو تاريخ.
البديل: تصنيف كل عنصر قبل الحفظ إلى Fact / Rule / Decision / Evidence / Open Issue / Historical Record / Operating Preference.
هـ. «إذا ما اكتمل»
المشكلة: لا يوجد تعريف لـ Done.
البديل: يعتبر التدقيق مكتملًا فقط عند تغطية: scope + extraction + contradiction check + provenance check + Notion reconciliation + unresolved items + persistence decision.
و. «نعم أو لا» في النهاية
المشكلة: لا يحدد السؤال الذي تجيب عنه نعم/لا.
البديل: تسمية المعيار صراحة، مثلاً:
«هل السجل الحالي كافٍ لإعادة بناء هذه المحادثة بعد حذفها؟ نعم/لا».
