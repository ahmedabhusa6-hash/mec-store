Oracle Cloud Always Free
Oracle states that Always Free resources are free for the life of the account in the tenancy's home region. The Always Free compute allowance includes up to 1,500 OCPU-hours and 9,000 GB-hours per month for Ampere A1, equivalent to 2 OCPUs and 12 GB RAM, plus 200 GB total Block Volume. Oracle documents capacity limits and possible out-of-host-capacity errors for Always Free shapes.
Classification:  Always Free Infrastructure / Core Runtime Candidate.
Source:  https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm
Cloudflare Workers + Workflows
Cloudflare documents Workers Free at $0 with 100,000 requests/day, and Workflows available on Free and Paid. Current Workflows Free limits include 3,000 steps/day, 1 GB-month state, 10 ms CPU per step, 100 concurrent running instances, 1,024 steps per workflow, 100 MB persisted state per workflow instance, 100,000 executions/day, and 3-day completed-instance retention. A Workflow instance can remain active indefinitely when individual steps obey their limits.
Classification:  $0/month / Free Tier limited / Durable Orchestration Candidate; not a general-purpose VM replacement.
Sources:  https://developers.cloudflare.com/workflows/reference/pricing/  and  https://developers.cloudflare.com/workflows/reference/limits/
GitHub Actions
GitHub documents standard hosted runners as free and unlimited for public repositories, but each hosted job uses a fresh runner. Scheduled workflows run from the default branch and can run as often as every 5 minutes. GitHub also documents self-hosted runners as free to use while the operator bears the machine cost; self-hosted runners do not require a clean instance per job and can run on cloud VMs.
Classification:  Scheduler/CI/Orchestration layer; not the Central Runtime by itself.
Sources:  https://docs.github.com/en/billing/concepts/product-billing/github-actions  ;  https://docs.github.com/en/actions/reference/runners/github-hosted-runners  ;  https://docs.github.com/en/actions/concepts/runners/self-hosted-runners  ;  https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax
Google Cloud Free Tier
Google documents one e2-micro instance per month in supported US regions plus 30 GB-month standard persistent disk. The allowance is time-based and shared across eligible e2-micro instances. This is a limited Free Tier path, not an unrestricted always-free VM, and the account model requires a billing account.
Classification:  Free Tier limited / Small Runtime Candidate.
Source:  https://docs.cloud.google.com/free/docs/free-cloud-features
AWS Free Tier
AWS currently offers up to $200 in credits for new customers with a six-month free-plan window, with the account closing after six months or credit exhaustion unless converted to Paid.
Classification:  Trial/Credit only / not an Always Free Production Runtime path.
