# Deployment — Accounting Systems Taxonomy Node
Initial rule
Deployment is a separate taxonomy dimension.
Evidence-backed values in this cycle
- Online / cloud-hosted
- On-premises
- Odoo.sh  as a distinct hosted cloud platform context
Non-assumptions
Deployment mode does not, by itself, determine System_Type. The availability of a deployment mode can also vary by product version, so Version and Deployment must be recorded together when material.
Status
ACTIVE as a taxonomy node; controlled vocabulary remains open for further evidence.
