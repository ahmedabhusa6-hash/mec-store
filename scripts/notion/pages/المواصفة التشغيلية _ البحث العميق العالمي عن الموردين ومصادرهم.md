## Content
## الهدف
هذا المستند يحول البحث من العثور على متاجر إلى نظام استكشاف سوق وسلسلة توريد رقمية.
**Discovery Breadth + Discovery Depth + Source Coverage + Price Coverage + Evidence Coverage**
## 1. فصل السياق عن البحث
بنية المشروع مرجع لفهم السياق والمنهج فقط. لا تُستخدم كمادة بحثية، ولا تُعتبر بياناتها دليلًا خارجيًا. أي بيانات سابقة تستخدم فقط كبذور، ثم يعاد التحقق منها خارجيًا.
## 2. التوسع التكراري
كل رابط أو متجر أو Channel أو Group أو Account أو Bot أو API أو Domain هو **Seed** جديد.
**Seed → Search Expansion → Entity Discovery → Entity Resolution → Relation Discovery → Upstream Search → Price Search → Evidence Search → Cross-Validation → New Seeds → Repeat**
## 3. خريطة سلسلة التوريد
**Seller → Reseller → Wholesaler → Master/Deep Wholesale → Distributor → Aggregator → Upstream Supplier → Primary/Original Source**
لا تفترض وجود طبقة غير مثبتة، ولا تجعل المصدر الأعلى مساويًا تلقائيًا للأرخص.
## 4. مسارات الاكتشاف
Product-first، Seller-first، Price-first، Channel-first، Bot-first، Username-first، Domain-first، API-first، SKU-first، Marketplace-first، Catalog-first، Document-first، Historical-first، Language-first، Infrastructure-first، Community-first، Advertisement-first، Referral-first.
## 5. هندسة الاستعلام
استخدم تركيبًا متعدد الطبقات:
**Product + Role + Commercial Term + Access/Proof Term**
أمثلة:
**PRODUCT + distributor + price list**
**PRODUCT + reseller + private catalog**
**PRODUCT + wholesaler + partner pricing**
**PRODUCT + supplier + API**
**PRODUCT + H2H + pricing**
**PRODUCT + dealer + net price**
**PRODUCT + bulk + MOQ**
**PRODUCT + distributor + custom quote**

## 9. معجم المصدر الأعلى

reseller API، wholesale API، B2B API، partner API، distributor API، catalog API، pricing API، inventory API، fulfillment API، order API، supplier API، aggregator API، white-label API، webhook، H2H، Host-to-Host، H2H pricing، H2H wholesale، H2H supplier، H2H integration.

## 12. البحث العكسي من السعر أو المحتوى
عند العثور على سعر منخفض أو وصف متكرر، ابحث عن:
**PRICE + PRODUCT**، **PRICE + SKU**، **PRICE + REGION**، **Exact Product Title**، **Exact Product Description**، **Exact Price Phrase**، **Exact FAQ**، **Exact SKU**.
الهدف اكتشاف جهات موازية أو مصدر مشترك، لا إثبات العلاقة بمجرد التشابه.
## 13. Domain / Username Discovery
related domains، associated domains، same certificate، same infrastructure، same IP، same ASN، same nameserver، same DNS، same analytics ID، same tracking ID، same payment provider، same support email، same Telegram، same username، same catalog.
Username: sales username، support username، reseller username، wholesale contact، partner contact، admin، owner، manager، account manager.
هذه إشارات اكتشاف فقط، وليست إثباتًا للعلاقة التجارية.
## 14. التحقق
كل ادعاء:
**Claim → Evidence → Verification Status**
افصل بين:
Displayed Price / Account Price / VIP-Dealer-Distributor Price / Volume Price / Negotiated Price / Checkout Price / Effective Acquisition Cost / Actual Transaction Price.
## 15. المطابقة السعرية
لا تقارن إلا بعد تثبيت:
**Brand، Product، Plan/Edition، Duration، Quantity/Face Value، Region، Activation، Account Type، Delivery، Restrictions**.
## 16. الضمان وإعادة البيع
الضمان:
**Documented Guarantee / Explicitly No Guarantee / No Documented Guarantee / Guarantee Unknown**.
إعادة البيع:
**Authorized / Resale Terms Available / Unclear / Restricted / Unknown**.
السعر ≠ الضمان ≠ المصدر ≠ حق إعادة البيع.
## 17. المخرج لكل نتيجة
**Entity → Role → Supply Level → Product/SKU → Region → Price → Price Type → Effective Cost → Availability → Guarantee → Resale Status → Upstream Claim → Upstream Evidence → Price Verification → Source Verification → Evidence URLs → Last Checked → Next Search Seeds**
## 18. المخرج لكل SKU
Cheapest Advertised، Cheapest Direct/Observed، Cheapest Without Documented Guarantee، Cheapest With Documented Guarantee، Known Upstream Supplier، Primary/Original Source عند ثبوته، Effective Acquisition Cost، Availability، Evidence، Last Checked، Exclusions.
## 19. البحث المستقل بين ChatGPT وz.ai
نفس الـSeeds ونفس تعريف الـSKU ونفس معايير التحقق، مع منع كشف نتائج النظام الأول للثاني قبل انتهاء الجولة المستقلة.
المقارنة تكون على:
**Unique Suppliers، Unique Upstream Sources، Unique Prices، Verified Relationships، Discovery Depth، New Discovery Paths، Duplicate Rate، Evidence Coverage**.
## 20. معيار «الأرخص»
لا تستخدم «الأرخص في العالم» كحقيقة.
الصياغة المعتمدة:
**«أقل سعر تم اكتشافه والتحقق منه ضمن نطاق البحث وتاريخ الفحص والشروط المحددة للـSKU»**.
## 21. قاعدة التوقف
لا توقف البحث عند العثور على مورد. أوقف **المسار المحدد** عندما تتوقف عمليات البحث المستقلة عن إنتاج جهات أو علاقات أو أسعار أو أدلة جديدة، مع تسجيل سبب التوقف.
## 22. الاختبار النقدي
راقب دائمًا: عدم إمكانية إثبات المصدر الأعلى، الأسعار الخاصة غير القابلة للتعميم، اختلاف الـSKU، التكرار، الاستنتاج من التشابه التقني، قيود إعادة البيع، وتقادم الأسعار والمخزون.
## 23. الحدود
العمل على المعلومات القابلة للوصول والتحقق المشروع. لا تتضمن المهمة كلمات مرور أو مفاتيح API مسربة أو تجاوز أنظمة الدخول أو استخراج بيانات خاصة دون تصريح.
## 24. الصيغة النهائية
**Canonical SKU → Multi-Path Discovery → Recursive Expansion → Entity Resolution → Supplier Graph → SKU Matching → Price Extraction → Cost Normalization → Guarantee Verification → Resale Verification → Upstream Tracing → Cross-Validation → Evidence Capture → Final Classification → Last Checked → Re-search**
## 25. معيار النجاح
النجاح = **أكبر عدد من الجهات الفريدة + أكبر عمق مثبت في سلسلة التوريد + أكبر تغطية سعرية قابلة للمقارنة + أكبر تغطية للأدلة + أكبر عدد من الاكتشافات الجديدة بين المسارات المستقلة**.
هذه المواصفة هي المرجع التشغيلي المتخصص لهذا الموضوع، ولا تحول أي Lead أو ادعاء أو سعر غير متحقق إلى حقيقة معتمدة.
