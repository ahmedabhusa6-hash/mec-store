1. Order Processing Fee

For most of the games on Z2U, we take a certain percentage from your income as Order Processing Fee.  But the Order Processing Fee might be changed for those special games.  

About the changes of processing fee, please refer to this link.


Default Order Processing Fee:  5%-9% 
According to different store levels, sellers can enjoy additional fee reductions.  Please refer to this Link.


Processing Fee of special games:  When the processing fee changes, we will mark the specific fee on the product management page, and games that are not mentioned will not be affected.

3. Revenue reserve 

For merchants with high-risk ratings, as well as some special games and listing types(Mostly high-risk projects), the platform will set an additional percentage of revenue reserve. We will mark the specific price when you submit the listing application, and it will be released to the sellers within a certain period. For more details, please refer to here 


4. Security Deposit

To ensure the benefits between platform and users(Include buyers and sellers) and protect the security of orders. Z2U will set up a Security Deposit for the seller who providing some specific products and services. The deposit value will base on the game popularity ranking, the minimum amount is 100 USD. For more details, please refer to here
