# قاعدة بيانات أرخص موردي ومتاجر المنتجات والخدمات الرقمية — الأرشيف المرجعي الكامل

> مستودع البيانات الرسمي لمشروع استخبارات الموردين — الفترة المشمولة: **2026-09-27 → 2026-10-02**

## ما هذا المستودع؟

يحتوي هذا المستودع على **الأصول البياناتية الكاملة** لمشروع قاعدة بيانات الموردين والمتاجر الرقمية: المخرجات النهائية الموثقة، الأدلة الخام من البحث الحي، مستخرجات Notion المرجعية (الحاكمة والتشغيلية)، بيانات الأبحاث الأولية، وسجل التشغيل الكامل متعدد الوكلاء.

> **ملاحظة بنيوية:** كود موقع الويب (mec-store) استُبعد من الفرع الرئيسي `main` بقرار المالك بتاريخ 2026-10-02 — نسخة نظيفة منه محفوظة في فرع `website-archive` للاحتياط.

## المراجع الحاكمة

- **المرجع الحاكم في Notion:** `مرجع حاكم — قاعدة بيانات أرخص موردي ومتاجر المنتجات والخدمات الرقمية`
- **السجل التشغيلي في Notion:** `موردين فقط`
- **الملف المرجعي للمشروع:** `download/PROJECT MASTER REFERENCE FILE.md` — وأرشيف الإصدارات السابقة في `download/PMRF_ARCHIVE/` (v1.5 → v3.2)

## الأمان والسلامة

- عُقّمت جميع مفاتيح API الحية من هذا الأرشيف (Acczone، ProdSeller، GitHub، Notion، Supabase) واستُبدلت بعلامات `[REDACTED-*]`.
- ملف `.env` **غير مضمّن إطلاقاً** ولا أي قواعد بيانات تشغيلية.
- **تاريخ نظيف:** يبدأ المستودع بـ commit جذر واحد نظيف — لا يحمل أي أسرار من التشغيل السابق.
- المستودع **خاص (Private)** — لا تجعله عاماً قبل مراجعة كاملة للمحتوى.
- على الرغم من التعقيم، يُنصح بتدوير (rotate) أي مفتاح وُجد يوماً في بيئة التطوير المحلية.

## كيفية الاستخدام

- ملفات **Markdown** تُعرض مباشرة داخل GitHub.
- ملفات **Word/Excel/PDF** تُحمَّل بالنقر عليها ثم زر **Download**.
- للبحث داخل الأدلة الخام استخدم شريط البحث في GitHub مع تحديد نطاق `research/`.
- `worklog.md` هو نقطة الدخول لفهم تسلسل العمل: اقرأه من الأعلى للأسفل (الأقدم أولاً).
