# أرشيف كود موقع الويب — mec-store

> **فرع أرشيفي احتياطي** — كود الموقع استُبعد من الفرع الرئيسي `main` بقرار المالك بتاريخ 2026-10-02، واستُبدل بأرشيف بيانات المشروع (انظر `main`).

## ما يحتويه هذا الفرع

آخر نسخة من كود **متجر MEC الرقمي** (Next.js 16 + Prisma + Supabase Postgres) كما كانت في بيئة التطوير، بما فيها تحسينات MEC-20/21 الأمنية والأدائية وواجهة تحميل التقارير.

## ما لا يحتويه (عمداً)

- `.env` — أسرار التشغيل (غير موجودة في أي فرع من هذا المستودع)
- `db/` — قاعدة البيانات المحلية
- `node_modules/` — تُستعاد عبر `bun install`

## للاستعادة إن لزم مستقبلاً

```bash
git clone -b website-archive https://github.com/ahmedabhusa6-hash/mec-store.git
cd mec-store && bun install
```

**تنبيه:** النشر الحي كان يتم عبر Railway من الفرع الرئيسي السابق — استبدال `main` بأرشيف البيانات أوقف مصدر النشر التلقائي. إن رغبت بإعادة تشغيل المتجر مستقبلاً، ابدأ من هذا الفرع.
