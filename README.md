# MEC — منصة استخبارات أسعار الموردين (Telegram)

نظام متكامل يجمع بيانات الأسعار من قنوات ومجموعات الموردين في تلغرام آليًا،
ويحوّلها إلى قاعدة معرفة حية تدعم قرار الشراء: موقع أسعار عام + لوحة تحكم
مالك (مصادقة، موافقات، أتمتة، جودة بيانات، تنبيهات، تدقيق، إعدادات).

## الحالة الإنتاجية

| المكوّن | المنصة | الحالة |
|---------|--------|--------|
| المراقب الآلي (v3) | GitHub Actions — كل 30 دقيقة + تشغيل فوري | إنتاجي |
| قاعدة البيانات | Supabase (Postgres + RLS) | إنتاجي |
| تطبيق الويب + اللوحة | Railway | إنتاجي |

## البنية

```
تلغرام → GitHub Actions (price-monitor/monitor.py) → Supabase → تطبيق الويب (Next.js 16)
```

- `price-monitor/` — المراقب: مسح تفاضلي، استخراج، اكتشاف، انضمام منضبط (شروط خدمة تلغرام)
- `src/` — تطبيق الويب: `/` قاعدة أسعار عامة، `/login` + `/dash` لوحة المالك
- `docs/ARCHITECTURE.md` — المعمارية الكاملة
- `docs/RUNBOOK.md` — دليل التشغيل والاستجابة

## الانضباط (شروط خدمة تلغرام — قراءة رسمية 2026-10-11)

- لا إرسال رسائل، لا إضافة أشخاص، لا تفاعلات — قراءة + انضمام عبر روابط معلنة فقط
- ≤3 انضمامات/دورة (≤2 خاصة) بفواصل عشوائية 12-30 ثانية
- سقف إجمالي 250 مصدرًا (حد تلغرام 500 — هامش أمان مضاعف)
- قواطع دوائر: PeerFlood → 48 ساعة، FloodWait → ≥6 ساعات (تلقائي)
- لا تدريب نماذج AI على البيانات (سياسة ترخيص المحتوى)
- الانضمام الخاص يتطلب موافقة المالك من اللوحة (بوابة awaiting_approval)
